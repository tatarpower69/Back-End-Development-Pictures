# Back-End-Development-Pictures
Flask Pictures REST API and PyTest tests for the Back-End Development Capstone.
## Environment Setup

This project is based on the Back-End-Development-Pictures template repository.

### Python Version
Python 3.9.x

### Virtual Environment
The virtual environment is named `backend-pics-venv`.

### Setup Instructions

1. Clone the repository.
2. Create and activate the virtual environment.
3. Run the setup script:

```bash
bash bin/setup.sh
```

4. Install the required dependencies.
5. Run the tests:

```bash
python -m pytest -v
```

The environment setup is complete when the setup script and tests finish successfully.
